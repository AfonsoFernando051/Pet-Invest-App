# Design System

## Overview

The Pet Invest App has an established visual identity.

This document defines the design principles, visual language, UI components, and user experience guidelines that should be followed throughout the application.

The objective is consistency, clarity, and a premium user experience.

This document should be considered the source of truth for every UI decision.

---

# Design Philosophy

Pet Invest App is **not** designed to look like a traditional banking application.

Instead, it should feel like a premium mobile game that teaches investing.

The interface should communicate:

- Progress
- Discovery
- Achievement
- Curiosity
- Exploration

Every visual element should reinforce the feeling that the user is progressing on a journey.

---

# Visual Identity

The application's visual identity is already established.

Do not redesign it unless explicitly requested.

Core characteristics:

- Futuristic
- Space themed
- Premium
- Modern
- Gamified
- Dark mode first
- Clean
- Minimalistic

The design should remain recognizable across all screens.

---

# Design Principles

Always prioritize:

- Simplicity
- Consistency
- Readability
- Visual hierarchy
- Accessibility
- Smooth interactions

Avoid unnecessary visual complexity.

---

# Color Philosophy

The interface is dark-first.

Primary colors should communicate energy and progression.

Accent colors should be used to guide attention, not decorate the interface.

Use color intentionally.

Avoid rainbow palettes or excessive color variation.

---

# Backgrounds

Backgrounds help establish atmosphere.

They should never compete with the content.

Background animations must be subtle.

The content should always remain the primary focus.

If users notice the background before the interface, the balance is wrong.

---

# Glassmorphism

Glassmorphism is part of the visual identity.

Use it in moderation.

Glass effects should:

- improve hierarchy
- create depth
- reinforce the premium appearance

Avoid excessive blur or transparency.

Not every container should use glass.

---

# Typography

Typography should prioritize readability.

Hierarchy should always be obvious.

Prefer:

- large section titles
- medium subtitles
- readable body text

Avoid:

- multiple font families
- decorative fonts
- inconsistent text sizing

Typography should guide the user naturally.

---

# Spacing

Consistency is more important than density.

Prefer an 8px spacing system.

Examples:

- 8
- 16
- 24
- 32
- 40

Maintain consistent spacing throughout the application.

Crowded layouts reduce perceived quality.

---

# Icons

Icons should be:

- simple
- recognizable
- consistent

Do not mix multiple icon styles.

Icons should support information, not replace labels.

---

# Cards

Cards are one of the primary UI components.

They should:

- organize information
- create hierarchy
- maintain consistent spacing
- have subtle elevation

Cards should never appear visually heavy.

---

# Buttons

Buttons should clearly communicate importance.

Primary actions should be visually dominant.

Secondary actions should remain visible but less prominent.

Destructive actions should always be distinguishable.

---

# Inputs

Input fields should feel premium.

Requirements:

- clear borders
- obvious focus state
- readable labels
- sufficient spacing

Validation messages should be easy to understand.

---

# Navigation

Navigation should feel effortless.

Users should always know:

- where they are
- where they came from
- where they can go next

Avoid deep navigation hierarchies.

---

# Animations

Animations should improve the experience.

They should never exist only because they look impressive.

Good animations:

- communicate state changes
- reinforce interactions
- improve continuity

Avoid long animations.

Prefer fast and smooth transitions.

---

# Microinteractions

Microinteractions are encouraged.

Examples:

- button press feedback
- page transitions
- progress animations
- level-up celebrations
- reward animations
- loading states

Microinteractions should make the application feel alive.

---

# Gamification

Gamification is part of the design.

UI should reinforce progression.

Examples:

- XP bars
- Levels
- Achievements
- Missions
- Daily rewards
- Unlock animations

Users should constantly feel that they are making progress.

---

# User Experience Principles

The application should feel:

- rewarding
- motivating
- intuitive
- responsive
- engaging

Avoid creating unnecessary friction.

Learning should be enjoyable.

---

# Information Hierarchy

Always prioritize information.

Users should immediately recognize:

1. Primary action
2. Current progress
3. Important information
4. Secondary information

Avoid presenting everything with equal visual weight.

---

# Responsiveness

The interface should adapt gracefully to different screen sizes.

Avoid hardcoded dimensions whenever possible.

Components should scale naturally.

---

# Empty States

Empty states should educate and encourage.

Instead of simply saying that no data exists, explain:

- why
- what the user can do next
- how to progress

Every empty state is an opportunity to guide the user.

---

# Loading States

Loading indicators should reduce perceived waiting time.

Prefer skeleton loaders when appropriate.

Avoid blocking the interface unnecessarily.

---

# Error States

Errors should be informative.

Never blame the user.

Explain:

- what happened
- what can be done
- whether retrying is possible

---

# Accessibility

Accessibility should always be considered.

Ensure:

- sufficient contrast
- readable text
- touch-friendly targets
- clear navigation

Accessibility improvements should never compromise usability.

---

# Consistency

Consistency is more important than originality.

Reuse existing components before creating new ones.

Users should immediately recognize familiar interaction patterns.

---

# What Should Never Change

Unless explicitly requested, preserve:

- The futuristic visual identity
- The space-inspired theme
- Dark-first design
- Premium appearance
- Gamification-focused experience
- Overall navigation philosophy

These elements define the personality of the product.

---

# Design Evolution

Future improvements should focus on refinement rather than redesign.

Priority order:

1. Better usability
2. Better consistency
3. Better spacing
4. Better animations
5. Better accessibility
6. Visual polish

Large redesigns are discouraged unless there is a clear usability problem.

---

# Guiding Principle

Every screen should answer the following question:

"Does this interface make learning investing feel enjoyable, rewarding, and premium?"

If not, reconsider the design.
